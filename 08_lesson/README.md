Дано:

Ссылка приложения https://en.yougile.com/

Полная API-документация доступна по ссылке https://requests.readthedocs.io/en/latest/

Методы для тестирования из раздела по работе с проектами:

- [POST] /api-v2/projects
- [PUT] /api-v2/projects/{id}
- [GET] /api-v2/projects/{id}

Требования:

- Использована библиотека pytest
- Использована библиотека requests
- Тесты стабильны (не требуют правки перед запуском)
- Есть позитивные и негативные кейсы для каждого метода
- Тесты запускаются через pytest
- Данные авторизации НЕ зашиты в коде (используется .env)
- Данные надо подставить в .env или вручную

Данные, которые нужно указать:

- EMAIL/LOGIN: адрес вашей почты
- PASSWORD: ваш пароль
- COMPANY_NAME: точное название вашей компании в Yougile
