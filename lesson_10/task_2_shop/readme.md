                    #  Автотест: Покупка товаров на https://www.saucedemo.com/

        ##  Описание

Проект автоматизирует полный путь покупки товара от логина до финального подтверждения
Тест проверяет полный сценарий покупки в интернет-магазине:

- Авторизация
- Добавление товаров
- Оформление заказа
- Проверка финальной суммы и сообщения об успешной покупке

        ##  Установка

Установить Allure:
[Инструкция для вашей ОС](https://docs.qameta.io/allure/#_installing_a_commandline)

        ##Что подключено и используется:

@allure.title, @allure.description, @allure.feature, @allure.severity — аннотации для Allure отчета.

with allure.step("..."): — для пошаговой детализации действий.

Проверки assert снабжены сообщениями для Allure.

Используется фикстура driver из conftest.py.

Используются все классы из pages/.

        ## Структура проекта

- `pages/` — классы страниц с методами взаимодействия
- `test/` — тесты
    - `config.py` — конфигурационные данные (URL, логин, пароль, данные покупателя)
        - `README.md` — инструкция по работе с проектом
